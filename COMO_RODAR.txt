EDITH - ASSISTENTE FINANCEIRA
=============================

ATALHO RAPIDO (WINDOWS)
-----------------------
De dois cliques em iniciar.bat. Ele cria o ambiente virtual, instala as
dependencias e abre a interface no navegador. Nas proximas vezes, use o
mesmo arquivo.


REQUISITOS
---------
- Python 3.10 ou superior
- Chave de API da Groq: https://console.groq.com/keys

O arquivo .env ja vem com uma chave configurada. Se ela nao funcionar,
gere outra em https://console.groq.com/keys e substitua o valor de
GROQ_API_KEY no arquivo .env.

A pasta .venv nao vem no ZIP. Ela e criada no seu computador na primeira
execucao, porque contem caminhos especificos da sua maquina.


INSTALACAO (WINDOWS - POWERSHELL)
---------------------------------
1) Abra a pasta do projeto no terminal:

   cd "caminho\onde\voce\extraiu\Projeto-Padrao-EDITH"

2) Crie o ambiente virtual:

   python -m venv .venv

3) Ative o ambiente virtual:

   .\.venv\Scripts\Activate.ps1

   Se aparecer erro de politica de execucao, rode uma vez:

   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

   No CMD, a ativacao e:

   .venv\Scripts\activate.bat

4) Instale as dependencias:

   pip install -r requirements.txt


RODAR O PROJETO
---------------
Interface web (navegador):

   streamlit run app.py

Versao no terminal:

   python chatbot.py

Se o comando streamlit nao for reconhecido, use o caminho completo:

   .\.venv\Scripts\python.exe -m streamlit run app.py

O navegador abre em http://localhost:8501. Para encerrar, use Ctrl+C.


INSTALACAO (LINUX / MACOS)
--------------------------
1) cd caminho/do/projeto
2) python3 -m venv .venv
3) source .venv/bin/activate
4) pip install -r requirements.txt
5) streamlit run app.py    (interface web)
   ou
   python chatbot.py        (terminal)


O QUE O EDITH FAZ
-----------------
- Registra gastos informados na conversa e guarda em um banco local.
- Monta a tabela do mes com total geral, total por categoria e cada despesa.
- Guarda memorias permanentes: nome, empresa, metas, preferencias e historico.
- Pesquisa cotacoes, noticias e indicadores atuais na internet e cita as fontes.
- Mantem personalidade fixa de assistente financeira seria e objetiva.
- Guarda varias conversas separadas, com historico no painel lateral.
- Tem interface escura no estilo Apple, responsiva para celular.
- No site publicado, cada visitante recebe um cofre vazio e exclusivo.


EXEMPLOS DE PEDIDOS
-------------------
- "Gastei 89,90 de internet hoje."
- "Registre 340,50 de supermercado no dia 12."
- "Monte a tabela dos meus gastos deste mes."
- "Qual foi o total de outubro por categoria?"
- "Exclua o lancamento 4."
- "Qual a cotacao do dolar e do Ibovespa hoje?"
- "Guarde que minha empresa atua no setor de logistica."
- "O que voce sabe sobre mim?"


ONDE FICAM OS DADOS
-------------------
No seu computador, tudo fica no arquivo edith.db, criado automaticamente
na pasta do projeto:

- mensagens: historico completo da conversa
- gastos: descricao, valor, categoria e data de cada despesa
- memorias: fatos permanentes informados por voce

Para fazer backup, copie o arquivo edith.db.
Para comecar do zero, apague o arquivo ou use os botoes do painel.
Nao compartilhe o edith.db: ele contem seus dados financeiros.

No site publicado, o edith.db do projeto NAO e usado. Cada aba do navegador
cria uma pasta temporaria propria, com um banco vazio, gerenciada pelo
arquivo sessao.py. Ao fechar ou recarregar a pagina, esse banco e descartado.
Assim, nenhum visitante ve os gastos, as memorias ou as conversas de outro.


VS CODE
-------
1) Abra a pasta do projeto no VS Code.
2) Ctrl+Shift+P -> "Python: Select Interpreter" -> escolha .venv
3) Aperte F5 e escolha:

COMANDOS UTEIS
--------------
- Atualizar dependencias:  pip install --upgrade -r requirements.txt
- Sair do ambiente virtual: deactivate
- Parar o Streamlit:        Ctrl+C
- Backup dos dados:         copiar edith.db

PUBLICAR NA INTERNET
--------------------
O Streamlit precisa de um servidor Python permanente, com WebSocket aberto.
Nao funciona em hospedagem de arquivos estaticos nem em funcoes serverless
curtas. Antes de publicar, confirme que o repositorio nao tem .env nem
edith.db; o .gitignore ja bloqueia os dois.

1) Streamlit Community Cloud (recomendado)
   - Suba o projeto no GitHub (repositorio ja criado:
     Gabriel-web-code/EDITH-Assistente-Financeira).
   - Acesse https://share.streamlit.io, clique em New app e escolha o app.py.
   - Em Advanced settings > Secrets, informe:
        GROQ_API_KEY = "sua-chave-da-groq"
   - Clique em Deploy.

2) Render (alternativa)
   - Suba o projeto no GitHub.
   - Acesse https://render.com, New > Web Service e conecte o repositorio.
   - O arquivo render.yaml ja traz o comando de inicializacao.
   - Em Environment, crie GROQ_API_KEY com a sua chave.

Privacidade no site:
- Cada visitante abre com banco vazio (sem gastos, memorias ou conversas).
- O botao "Apagar meus dados" limpa a sessao na hora.
- Os dados ficam apenas na aba do navegador e somem ao recarregar a pagina.
- A chave da Groq e unica para todos os visitantes; acompanhe o consumo em
  https://console.groq.com.
